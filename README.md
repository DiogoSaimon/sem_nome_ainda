# sem_nome_ainda

É um projeto pessoal para catalogar todos os filmes, séries e animes assistidos pelo usuário. 
A inspiraçao veio de sentir que o Letterboxd não atende bem séries e anime, ele brilhar nos filmes e na comunidade em si.

Este projeto começará inicialmente com:

- Acesso via gmail;
- Edição de perfil;
- Pesquisar pela obra que deseja ter informações ou adicionar que foi assistido;
- Tela com informações da obra;
- Tela de adição da obra que foi assistido;
- Tela com os seus assistidos, contendo filtragem por Todos, Filmes, Séries e Animes;
- Tela de com sua lista pessoal que Deseja Assistir;

- A versão mobile serão mobile first para uma melhores experiência ao usuário.


## Segue aqui a arquitetura do projeto:

- Esse projeto será dividido entre mobile e web, com repositórios divididos ambos usando Flutter;

O motivo disso é que a versão web pode conter algumas limitações da própria plataforma, e indentificando isso, teria a liberdade de ir para o React.

Foi usado o agente da Manus AI para ajudar nas referências de criação desse projeto, caso queira visualizar as sugestões, acesse a pasta <b>manus_ai_references<b>
